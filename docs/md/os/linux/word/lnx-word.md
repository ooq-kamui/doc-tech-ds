
# linux word


### wayland

- Linux / Unix 系 OS におけるディスプレイサーバープロトコル.  
  従来の X Window System (X11) を置き換える目的で設計され,
  クライアント (アプリケーション) とコンポジタ (画面合成を行うサーバー) が直接通信する構造を持つ.
  X11 に比べてレイヤーが少なく, セキュリティ・描画性能・入力処理の面で改善されている


### fcitx 5

- Linux 向けのインプットメソッドフレームワーク (入力メソッドの管理基盤).
  Fcitx 4 の後継で, モジュール構造が刷新されている.
  日本語・中国語・韓国語などの入力エンジンをプラグインとして組み込み,
  アプリケーションへのテキスト変換・候補表示を仲介する役割を担う.
  Wayland 環境では text-input プロトコルを介して動作する


### mozc

- Google が公開しているオープンソースの日本語入力エンジン (かな漢字変換エンジン).
  Google 日本語入力と共通のコードベースから派生しており, 変換精度の高さが特徴.
  単体では動作せず, Fcitx 5 や IBus などのインプットメソッドフレームワーク上にプラグインとして載せて使用する

---

### Wayland, Fcitx 5, Mozc の関係

- Wayland : 画面描画と入力イベントを扱うプロトコル層
- Fcitx 5 : その上で動くインプットメソッドフレームワーク
- Mozc    : Fcitx 5 に組み込まれる日本語変換エンジン
