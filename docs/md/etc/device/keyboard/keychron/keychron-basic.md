## layer

```
MO (Momentary): 押している間だけ指定レイヤーに切り替える
- 一般的なキーボードの「Fnキー」と同じ挙動です
  キーを離すとすぐに元のレイヤーに戻ります

TG (Toggle): ボタンを押すたびにレイヤーのON/OFFを切り替える
- 「Caps Lock」や「Num Lock」のような挙動です
  1回押すとそのレイヤーに固定され、もう1回同じキーを押すと元のレイヤーに戻ります

TT (Tap-Toggle): 長押しと連打で挙動が変わるハイブリッド機能です
- 長押ししている間は「MO」になり、素早くトントンと連打（初期設定では5回、またはVIAの設定回数）すると
  「TG」のようにそのレイヤーに固定されます

OSL (One-Shot Layer): 次の1キーだけ指定レイヤーに切り替える
- このキーを1回押した後に「別のキーを1つ押す」と、そのキーだけが移動先レイヤーの挙動になり、
  入力が終わると自動で自動的に元のレイヤーに戻ります
- キーを長押し（ホールド）した場合は、「MO」と同じ挙動になります
  つまり、「キーを押している間だけそのレイヤーに切り替わり、
  離すと元のレイヤーに戻る」という動きになります
  OSLキーは、押し方によって自動的に次の2つの挙動を使い分けてくれる非常に便利な機能です

TO (To): 指定したレイヤーへ完全にジャンプする
- 他のすべての一時的なレイヤーを強制的にOFFにして、指定したレイヤーを有効にします
  ゲーム用レイヤーなどへ一発で完全に切り替えたいときに使います

DF (Default): ベース（基本）となるレイヤー自体を変更する
- キーボード全体の「土台」を切り替えます
  例えば「Windows用配列（レイヤー0）」から「Mac用配列（レイヤー1）」へ、
  土台そのものを永続的に切り替える場合などに使用します
```
