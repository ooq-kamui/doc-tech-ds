
## lightning

```
RGB Toggle バックライトの on / off
Mode-      発光エフェクト prv
Mode+      発光エフェクト nxt
Br-        Brightness を dn
Br+        Brightness を up
Hue-       Hue(色相) dn
Hue+       Hue(色相) up
Sat-       Saturation(彩度) dn (色が 薄く/白っぽく なる)
Sat+       Saturation(彩度) up (色が 濃く/鮮やかに なる)
ES-        Effect Speed を dn
ES+        Effect Speed を up
```
